# PhotoCleaner（静照）— AI 驱动的智能照片清理工具

> 从 0 到 1 完成的 AI 产品项目：产品设计 → 交互原型 → 工程落地 → AI 集成

---

## 📱 项目简介

PhotoCleaner 是一款帮助用户快速清理手机冗余照片的工具。通过**随机分组 + 手势标记 + 对比模式**降低决策成本，集成**本地 AI 模糊检测**自动识别低质量照片。

**核心价值：用最低决策成本，快速识别并删除废片，释放存储空间。**

---

## 🎯 解决的问题

| 痛点 | 解决方案 |
|------|---------|
| 照片太多，逐一筛选太慢 | 10 张一组，批量处理 |
| 相似照片太多，对比困难 | 智能分组 + 2×2 对比模式 |
| 时间线排列造成审美疲劳 | 组内随机打乱，降低判断干扰 |
| 模糊照片难以发现 | AI 清晰度评分 + 标签提示 |
| 隐私担忧 | 纯本地处理，不上传任何数据 |

---

## ✨ 核心功能

### 📷 照片管理
- **大图浏览模式（默认）**：沉浸式单张浏览，左右滑动切换
- **手势标记**：上滑保留 / 下滑删除，操作流畅直觉
- **网格缩略图**：3 列网格总览，标记状态一目了然
- **双指缩放**：1x-5x 自由缩放，检查照片细节
- **用户上传**：支持从设备选择照片导入

### 🔍 对比模式
- **勾选选择**：从网格中自由勾选 2-4 张照片
- **2×2 并排对比**：同一屏幕对比相似照片
- **点击保留**：点击选择最佳照片，其余标记删除

### 🤖 AI 智能辅助
- **清晰度评分**：浏览器端 AI 模型检测照片质量
- **智能标签**：自动标记「疑似模糊」照片
- **完全本地化**：AI 推理在浏览器完成，保护隐私

### 🗑️ 回收站机制
- **软删除**：标记删除的照片先进入回收站
- **撤销操作**：支持单步撤销和一键恢复
- **空间统计**：实时显示可释放的存储空间

## 🧱 技术架构

```

PhotoCleaner
├── 前端：原生 HTML/CSS/JavaScript + Tailwind CSS
├── AI 推理：TensorFlow.js（浏览器端本地运行）
├── 部署：GitHub Pages
└── PWA：支持离线使用 + 桌面安装

```

### 技术亮点

| 技术 | 说明 |
|------|------|
| **纯前端架构** | 无后端、无数据库，极致轻量 |
| **端侧 AI 推理** | 照片质量检测完全在浏览器完成 |
| **PWA 支持** | 可添加到手机桌面，全屏沉浸体验 |
| **响应式设计** | 手机/平板/桌面均可使用 |
